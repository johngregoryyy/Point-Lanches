# Point-Lanches
Sistema PDV e de tele-entrega offline-first em Python e CustomTkinter para lanchonetes. Inclui catálogo ágil, busca rápida de ruas de Dois Irmãos, impressão térmica ESC/POS para Elgin i8 com destaque visual, histórico de comandas, balanço mensal com gráficos e atualização automática via GitHub Releases.
